# Juan Abel ANzo Mendez

Este es un proyecto de primeros pasos en VR utilizando Unity con los Oculus Quest, se ejemplifican las funcionalidades del XR Interaction Toolkit
se muestran elemenetosinteractivos usando las propiedades del rigbody
movement type: kinematic, velocity instantanius
Se implemento el uso de triggers par cambiar los colores del material de un objeto.
Incluye el locomotion sistem para moverse dentro del entorno con los controladores Oculus.

## Instrucciones para ejecutar el proyecto
Para ejecutar el proyecto es necesario tener conetados los oculus a la computadora. 
Los oculus deverab tener activada a la opción de desarrollador.
Seleccione los oculus como dispositivo de depuración en el los "Project Settings"
Cargue la Scena, ejecute el programa desde "Build and Run"
